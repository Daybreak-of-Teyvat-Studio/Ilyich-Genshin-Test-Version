## 本机沙箱写权限（实测，务必记住）

- 子进程（bash / PowerShell / python）在工作区内：**新建文件可以**；**覆盖已存在文件、删除任何文件一律失败**。
- 删除被 harness 接管并转给 `genie-trash`，该工具在本工作区报
  `Error during a 'trash' operation: Unknown { description: "Some operations were aborted" }`，
  然后 `SAFE_DELETE_FAIL_CLOSED` 直接拒绝。`dangerouslyDisableSandbox: true` 也**无效**（同一拦截层）。
- `mv` 因此失败：同盘 rename 若目标不存在才能成功，目标已存在报 `Permission denied`（EACCES）。
- 结论：需要“改动 MOD 里已存在的文件”时，**只能用内置 Write / Edit 工具**（它们能写已存在文件）；
  BMP 这类二进制只能**每次输出新文件名**，再改 `default.map` 之类的文本指向它。
