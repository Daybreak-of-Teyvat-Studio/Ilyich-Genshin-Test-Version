### ★本轮最大突破：眼睛为什么一直不显示
**根因不是 z-fighting，是「叠层太多 + 脸皮遮挡」。**
1. 原模型把一只眼拆成 5 个同轴叠层：`白目`(眼白) / `目`(虹膜) / `瞳`(瞳孔) /
   `目光`(高光) / `星目`(星形眼)。MMD 靠**材质绘制顺序**分层，HOI4 只有**深度测试** → 必然互相遮挡。
2. 实测（`scripts/eye_only.py`，逐材质单独渲染）：**只留 `目` 一张就是一只完整正确的眼睛**
   —— 眼白、虹膜、瞳孔、高光、下眼睑那朵花**全都画在 `目.png` 里**。
3. 于是把 `白目/瞳/目光/星目` 全部加进 `EXCLUDE_KEYS` 整层剔除，眼 = 单个 `目` 材质。
4. 剩下一件事：`目` 被脸皮 `颜/颜2` 盖住 → 沿视线方向（-Z）整层前推。
   前推量用 `scripts/eye_push2.py` 扫描定出（只留 颜/颜2/睫/目）：
   `0.010` 只露下半 / `0.020` 大半 / **`0.030` 完整** / `0.045` 完整且最饱满（采用） / `0.060` 仍正常。
   阈值约 0.025，**取 0.045**（≈身高的 0.6%）。
5. 验证：两种深度规则（`<` 与 `<=`）渲染差 **最大 9/255，仅 39/1,000,000 像素差 >8** → 结果稳定。

### 缺陷 1：走路两腿交叉成 X —— 根因是腿身比错配
- 源（薇斯纳 PMX）：大腿根 y=11.22 / 頭 y=16.88 → 腿:躯干 = **1.78**
  HOI4 骨架：LeftUpLeg y=3.456 / head y=6.505 → **1.11**
- 整体相似变换后残留偏差：大腿根 0.84 / 膝盖 0.55 / 脚踝 0.77 / 脚尖 0.92
  → 蒙皮时每根骨绕**它自己的原点**旋转，而该原点离真正的腿 0.8~0.9 远 → 绕错圆心摆、互相穿插
- 证明骨架是硬契约（`scripts/rig_check.py`）：
  - PRC/Keqing/Amber/Furina/Kokomi/Citlali 的骨架 rest 位置**逐字节一致**（偏差 0.000）
  - Keqing 腿几何 x = 0.58/0.72/0.93（骨架 0.44/0.67/0.88）；我们旧版只有 0.28/0.31/0.15
  - PRC_infantry 自己的脚底就在 x≈±1.076（骨架的宽站姿是真的）
- **解法 = bind conform（改绑定姿态）**：绑定时每根骨都是纯平移，
  `v' = v + Σ w_i·(q_i − p_i)`，即按蒙皮权重加权平均各骨的位移向量。
- **必须排除**（`scripts/conform_probe.py` 实测 disp）：翅膀骨 `左上翼_16` disp=4.118（会把翅膀拽成点）、
  长发 `髮_26`、IK 骨 `足ＩＫ` 3.1（无权重）、裙骨、物理骨、表情骨。
- ⚠ 索引别混：`disp` 按**源骨**（550 根）索引，写成 `0 <= b < 33` 会让绝大多数顶点算不出位移。
- 效果：腿部几何 x 剖面 0.369/0.706/0.894/1.140 vs 骨架 0.436/0.667/0.881/1.136（差 ≤0.067）。
- 代价（可接受）：腿被等比压缩 ~23%，腰/大腿根有一段平滑过渡、裙摆略走样。

### 修正：conform 第一版把大腿小腿撕开了（用户发现）
用户看 `preview_T_sheet` 指出「大腿和小腿是错位的」。
- **取证**：放大腿部特写渲染（`--zoom 2.8 --focus-y 1.7`）确认膝盖处**真有几何断口**；
  再渲染 `vysna_final`（未做 conform）对照 → **腿部完全连续、膝盖光滑**
  ⇒ 断口是 conform 引入的，不是模型自带。脚本 `leg_profile.py` 量化（按 y 分带 mean x）。
- **根因**：第一版 conform 是「每根骨一个常量位移 `disp_i = q_i − p_i`」= **分段常量位移场**。
  相邻腿骨目标位相差极大：

  | 关节 | disp_x | disp_y |
  |---|---|---|
  | 大腿根 | +0.065 | −0.839 |
  | 膝盖 | +0.417 | −0.343 |
  | 脚踝 | +0.761 | +0.071 |
  | 脚尖 | +0.917 | 0.000 |

  蒙皮权重在膝盖处从「腿骨」切到「膝骨」→ 位移**跳变 0.35~0.5** → 网格被撕开。
- **修法**：对每条腿把位移改成**沿 y 的连续插值曲线**：
  锚点 `(源骨拟合后 y, disp)` 按 y 升序，顶点 `np.interp(y, ys, ds)`；
  再与其它骨的位移按蒙皮权重混合（保证髋部过渡平滑）。
  锚点间斜率实测几乎一致（0.184 / 0.173）→ 位移场近似一条直线 →
  腿变成**平滑地「外展 + 缩短」**，膝盖断口消失且走路仍不交叉。
  ⚠ 锚点集合要含映射到该腿的**全部**源骨（含 `左足D`/`左ひざD` 这类变形骨），否则它们退回常量位移。
