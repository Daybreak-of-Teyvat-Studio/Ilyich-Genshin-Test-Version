## 一、结论速览

**胜利点悬空的唯一根因**：8 个州文件里的 `victory_points` 写成了 **4 个参数**。
HOI4 该语句**只接受 2 个参数**，参数超限时引擎直接**丢弃整条语句**，
导致这些州的所有胜利点都没被登记 —— 游戏里就表现为"悬空 / 不存在"。

**责任提交**：`ceea236d`「地图粗修2」（作者 kevinkarens，2026-09-24 15:35）
该提交共修改 203 个州文件，恰好这 8 个的 `victory_points` 被从合法写法改成了非法写法。

**修复状态**：✅ 已完成。8 个文件全部拆成合法的"每省一条"，全 MOD 复扫干净。

## 三、正确语法

```
victory_points = { <province_id> <value> }
```

**一条语句只能写一个省**。要标多个省就写多条：

```
victory_points = { 1582 1 }
victory_points = { 2394 1 }
```

## 六、附：`map/positions.txt` 坐标映射标定（本次顺带查清）

格式为花括号块，**不是** 每行 `id=`：

```
1={
	position={
		1873.139 9.500 1684.197     ← 6 行，同值
	}
	rotation={ ... 6 个 0.000 ... }
	height={ ... 6 个 0.000 ... }
}
```

- **坐标映射：`col = x, row = z`（直接对应）** —— 与 `provinces.bmp` 匹配命中率 **99.8%**
- `y` 恒为 `9.500`，是高度占位值，**与行列无关**（不能拿它当行号）
- 全图 400 省抽样：99.8% 落在陆地，中位高程 119
