## 3. 本轮已修：batch 8 + batch 9（共 30 处 / 8 个文件）

### batch 8 —— `has_game_rule` 把「规则名」当「规则 id」用（20 处）

**根因**：`common/game_rules/DOT_Midnight_Mode.txt` 里每个规则的**块名是 id**、`name =` 后面才是**本地化键**：

```hoi4
MOT_Way = {                      # ← 这才是 rule id
    name = "MOT_ChoosetheWay"    # ← 这是本地化键，不是 id
    ...
}
```

而脚本里写的是 `rule = MOT_ChoosetheWay`（用了 name）→ `has_game_rule: game rule MOT_ChoosetheWay does not exist`。

**证据（三重）**：
1. 同一个 MOD 的**其它地方已经写对了**：`rule = MOT_Way` / `rule = RAG_Way` / `rule = DRA_Way` / `rule = AN_Way`；
2. `option =` 的值能逐一对上目标规则的 option 表（`MOT_NoelleWay_Communism/Fascism/Democrazy` 全在 `MOT_Way` 里；`MOT_FAVLeftUnion_Route/RightUnion_Route` 在 `FAV_Way` 里；`MOT_ANQ1/2/3` 在 `AN_Way` 里）；
3. 原版 1,982 处 `has_game_rule` 全是 `{ rule = <块名> option = <option名> }`。

| 文件 | 行号 | 原 | 改为 |
|---|---|---|---|
| `events/NewMOT_Knights_event.txt` | 4069/4073/4077/4108/4112/4116/4324/4332/4336/4352/4360/4364 | `rule = MOT_ChoosetheWay` | `rule = MOT_Way` |
| `common/decisions/FAV_decisions.txt` | 4242/4246 | `rule = MOT_ChooseFAVWay` | `rule = FAV_Way` |
| `events/ANR_Andrius_event.txt` | 437/444/451/464/471/478 | `rule = MOT_ChooseAndWay` | `rule = AN_Way` |

> 影响：这 20 处此前**恒为假**（规则查不到 → 触发器失败），脚本里的 `OR` 分支等于死代码。修好后「西风骑士团路线 / 安德留斯路线」等真正的分支判断才会生效。
