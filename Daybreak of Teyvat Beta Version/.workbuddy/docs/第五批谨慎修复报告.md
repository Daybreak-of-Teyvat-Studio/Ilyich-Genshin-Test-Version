### batch 6 —— 8 个角色文件的结构修复（9 处角色定义）

**症状**（`common/characters/*_Characters.txt`）：

```
portraits = {
    civilian = { large = ... small = ... }
    army     = { large = ... small = ... }
    corps_commander = {          <-- 角色块被塞进了 portraits 里
        traits = { ... }
        skill = 2
    }
}
```

**裁判**（手册《Character modding》）：

> Portraits fall into 3 categories: `civilian`, `army`, and `navy`.

即 `portraits` 只能装这三个分类；`corps_commander` / `field_marshal` / `country_leader` / `navy_leader` 必须是 `portraits` 的**兄弟节点**。原版 20 个角色文件实测：角色块出现在 `portraits` 内 **0** 次、出现在 `portraits` 之后 **238** 次。

**修法**：把 `portraits` 的收尾 `}` 上移到第一个角色块之前 —— **括号总数不变**，纯位置调整。

涉及文件：`BRF` / `CYG` / `FON` / `GYP` / `KQP` / `LYY` / `SHP` / `YLH` `_Characters.txt`（其中 `FON_Characters.txt` 的同一个 `portraits` 里塞了 `country_leader` + `field_marshal` 两个角色）。

**验证**：MOD 全部 characters 文件共 **459** 个角色块，现在全部位于正确层级（depth = 2）；仍有角色嵌在 `portraits` 内的 = **0**。

> **影响提示**：这会**激活作者已经写好的将领/领袖角色**（此前因括号位置错误被引擎整块忽略）。如果你不想要这个副作用，用 `hoi4lint\backup_MOD_batch6\` 一键还原即可。
