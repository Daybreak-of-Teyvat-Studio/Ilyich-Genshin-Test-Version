用户明确要求（2026-10-17）：①**回复尽量简洁**，命令**无歧义**；②**不要总是问 nudge 好了没有**——有问题他会直接告诉我；③skill 使用时（输出/记录）也同样简洁无歧义。

**Why:** 反复追问同一状态浪费用户时间、显得啰嗦。

**How to apply:** 汇报一次即止，不追发"请确认 X 是否正常"；结语只陈述已完成事项与遗留项，把是否需要反馈留给用户主动提出；写命令/指令（含 skill 内的命令示例）用词精确、格式统一。**思考过程也要精简**：不要反复感叹词/自我重复（用户点名"'hmm'堆太多，别乱花 token"），直接给结论、数据与下一步。
