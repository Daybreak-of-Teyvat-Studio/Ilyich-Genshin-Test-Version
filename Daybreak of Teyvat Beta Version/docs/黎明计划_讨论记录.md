# 黎明计划 — 初步讨论记录

## 基础设定

| 项目 | 内容 |
|------|------|
| 主导国家 | DVA（公社/高塔研究所） |
| 原型参考 | 生化奇兵：无限的天空之城哥伦比亚 |
| 天空城代号 | 黎明计划 |
| 模型方案 | 基于现有 Big Ben mesh 改造为浮空城结构 |

## 天空城基建

- 表现形式：地图外工厂（offmap）+ 地图上方可见模型
- 建设方式：决议驱动
- 升级路径：浮空平台 → 生活区 → 工业区 → 研究区 → 始源光核心
- 每级增加 offmap 民工/军工/核反应堆

## 外交与资源获取

- 前置条件：向目标国派遣使团建交
- 科研小队获取资源：
  - 须弥：能量块
  - 枫丹：荒芒能量块、始基矿
  - 纳塔：燃素（载体）
- 用途：光界力研究 + 天空城燃料

## 双轨研究项目

### 轨道一：曙光计划（阿贝多+砂糖）

- 创生小杜林 → 加入内阁
- 通过转生方式摆脱命之座（天理命运管理系统）控制
- 目标：成为超越者（与降临者同位格，掌握光界力）
- 小杜林同时纳入火种计划

### 轨道二：解析世界式

- 龙脊雪山考古队 → 枫丹水仙十字遗址 → 回收雷内笔记
- 邀请博絮埃 → 参与天空城研发
- 与愚人众交易 → 换取木偶的笔记副本（公开会引发不满）
- 还原世界式约 80%
- 研究结果：
  - 全民元素力公开（全兵种穿深+突破加成）
  - 七元素合一理论

## 终局抉择

### 光界力能源问题

七元素合一需要七神神之心创造永续光界力 → 与至冬女皇计划冲突

- **主战线**：对至冬开战，夺取神之心 → 始源光装置（近乎无限光界力）
- **复仇线**（无神之心）：效仿雷电将军千手百眼神像，强制征收神之眼
- **温和线**（无神之心）：召集卫星角色轮流供给，安柏邀请丝柯克，争取魔女会（艾莉丝、芭比洛斯）支援

### 命运对抗

- 深渊：编织漆黑命运
- 天理：利用地脉记录编织命之座
- 深渊教团：使用命运织机从地脉中删除自身

公社的两种应对：

| 路线 | 方向 | 核心角色 | 游戏效果 |
|------|------|----------|----------|
| 安柏线 | 创造新命运系统 | 安柏 | idea + 全民元素力 + 全兵种加成（穿深/突破） |
| 莫娜线 | 创造超越者 | 莫娜/杜林 | idea + 超级强力角色杜林（将领+内阁双栖） |

## 安柏线史诗感设计

五层递进表现恢弘叙事：

1. **多阶段事件链**：觉醒 → 冲突 → 破天 → 决战 → 之后
2. **递进动态精神**：每阶段付出代价换力量（稳定下滑/天罚debuff 换取战力提升）
3. **视听层**：news_event 通知全世界、改国家颜色、替换BGM
4. **文学化中文叙事**：关键时刻用沉浸式文本替代简报体
5. **节奏控制**：铺垫 → 催化 → 高潮（虚假之天碎裂，多日连续事件）→ 余波（各国反应）→ 新常态
