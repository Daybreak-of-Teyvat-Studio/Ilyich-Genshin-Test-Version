## heightmap 柔化（用户指定规则）

**输入**：`Gamma Version\map\heightmap.bmp`，4096×2048、8bpp 调色板 BMP。原状：海洋一律 **89**，陆地 **97–200**，灰阶仅 105 个。
**要求**：灰度 10=最低、94=海平面、255=最高峰；与陆地相接的海面=93，之后 1px→90、5px→70、10px→50、20px→30；所有陆地 ≥96，沿海陆地=96，过渡平滑。

**做法**（脚本在 `.workbuddy\mapgen\`）：
- 掩膜 = `arr >= 94`（海洋 89 与陆地 97 之间是空档，阈值任意取 90–96 都行）。**掩膜全程不改**，只改灰度值。
- 海面：`distance_transform_edt(sea)` 得到"到最近陆地的欧氏距离 r"，灰度 = 分段线性过锚点 r=1/2/6/11/21 → 93/90/70/50/30；r>21 用三次 Hermite（p=20t²-40t+30，t=(r-21)/20）在 r=41 处把斜率收到 0、值落到 10，之后恒为 10。这样整条剖面 C1 连续，没有折角环。
- 陆地：掩膜内归一化高斯 `gaussian(arr*land)/gaussian(land)`（sigma=2.0，由扫描选定）得柔化高程；再乘 smoothstep 抬升门 `w=smoothstep((d_land-1)/11)`，`new = 96 + w*(blur-96)`，d=1 处恰为 96，d≥12 处与原图一致。最后 `clip(..., 96, 255)`。
- 写盘：**逐字节沿用原文件的 54 字节头 + 1024 字节调色板**，只替换像素数据（`out[::-1]` 转 bottom-up），并回填 bfSize/biSizeImage。这样不依赖 PIL 的 BMP 写法，格式零风险。

**实测结果（回读磁盘终检）**：
| 检查项 | 结果 |
|---|---|
| 所有陆地 ≥96 | ✅ min=96 max=187 |
| 沿海陆地 ==96 | ✅ d==1 的 30191 px 全部=96 |
| 海面 ≤93 | ✅ max=93 min=10 |
| r=1/2/6/11/21 的海面灰度 | ✅ 93.00 / 90.00 / 70.00 / 50.00 / 30.00（分毫不差） |
| 海陆交界落差 | ✅ 44984 对**全部等于 3**（96−93） |
| 陆地内部相邻落差 | 均值 9.21→**1.59**，p99 60→8，max 103→**15** |
| 全图最大落差 | 103 → 15；落差 ≥16 的邻接对：362916 → **0** |
| 灰阶数 | 105 → 167（渐变更细腻） |

**副作用**：峰高 200→187（高斯柔化所致）；海洋 85% 面积落到 10（近黑），视觉上从"均匀中灰"变成"近岸亮环+深海黑"，这是规则 10=最低 + 20px→30 外推的必然结果。

## terrain.bmp 按高度涂山地色（用户指令）

**要求**：把 heightmap 中「高亮白色部分」在 `map\terrain.bmp` 上涂成山地色。经两轮确认，最终取
**阈值 ≥175**、**颜色 (58,131,82)**（原版调色板索引 20 = `mountain_variation_grass`，`00_terrain.txt` 里 `type = mountain`）。
用户中途试过 (255,255,255)（= 索引 16 `snow_16`，同为 mountain）与 (243,199,147)（= 索引 31 `desert_mountain_tops`），最后定为 (58,131,82)。

**关键格式事实**：
- `map\terrain.bmp` 是 **24bit 无调色板 BMP**（off=54, w=4096, h=2048, bottom-up）。MOD **不覆盖** `common/terrain`，
  用的是原版 `common/terrain/00_terrain.txt`。该 MOD 的 terrain 配色走 **categories 颜色匹配**：
  forest(89,199,85) / hills(248,255,153) / plains(255,129,66) / marsh(76,96,35) / jungle(127,191,0) 五个都与 categories 的 color 精确相等。
- **BMP 24bit 磁盘字节序是 BGR**！用 numpy 直接 `out[::-1].tobytes()` 写会红蓝互换（第一次就踩了，回读全图 8388608 px 全不同）。
  正确写法：`out[::-1, :, ::-1].tobytes()`。
- 原版调色板参考：16=(255,255,255) snow_16(mountain)、20=(58,131,82) mountain_variation_grass、31=(243,199,147) desert_mountain_tops。
  categories 里 `mountain` 的 color 是 (157,192,208)。

**交叉统计**（地形色 × 高度带）：hills(淡黄) 覆盖 155–164 的 71%、165–174 的 95%、175+ 的 99.8%；即高地以上原本全是 hills。

**做法**：脚本 `.workbuddy\mapgen\paint_terrain_mountain.py`
`--out=<路径> [--th=175] [--minpix=0]`。`mask = (hm>=94) & (hm>=TH)`，`out[mask]=COLOR`，沿用原 54 字节头、只换像素体。

**结果（基于当前 heightmap，max=181 那版）**：命中 2647 px（占陆地 0.46%），25 个连通块，最大 1309 px 位于 y=474 x=1959；
被覆盖原色 99.9% 是 hills 淡黄。回读校验：目标色 2647 px、与原 terrain 差异恰好等于 mask、非命中区一字未动。
